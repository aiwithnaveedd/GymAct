# Content Required From Gym Owner

This is everything needed to replace placeholders with real content. Nothing on this list will be invented — pages will use clearly marked placeholders until real information is supplied.

---

## Required Before Development Starts

These block meaningful progress on Phase 1–3 of the roadmap (setup/design system/homepage can start, but real content needs these):

- [ ] **Gym name** (exact legal/brand name as it should appear)
- [ ] **Logo** (vector/high-res, ideally with a transparent background)
- [ ] **Tagline/slogan** (if one exists)
- [ ] **Full address** (for map, footer, schema markup)
- [ ] **Phone number**
- [ ] **WhatsApp number** (may be same as phone)
- [ ] **Email address** (for contact form delivery and footer)
- [ ] **Opening hours** (per day, including any weekend/holiday differences)
- [ ] **Google Maps location** (share link or exact coordinates)
- [ ] **Social media links** (Instagram, Facebook, TikTok, etc. — whichever are active)
- [ ] **Brand colors** (if any exist already; otherwise we propose a palette per §7 of the blueprint)
- [ ] **Existing branding/style guide** (if any — fonts, logo usage rules, etc.)
- [ ] **At least 15–20 real photos**: gym exterior, interior/facilities, equipment, trainers, and (ideally) members training — no stock photography will be used
- [ ] **About/story content**: how the gym started, its philosophy/mission, what makes it different
- [ ] **Trainer information** per trainer: name, role/title, specialization, years of experience, short bio, photo, social handles (optional)
- [ ] **Facilities list**: what equipment/areas/zones exist (e.g., free weights, cardio zone, functional training area, locker rooms)
- [ ] **Services/classes offered**: e.g., personal training, group classes, nutrition guidance — with a short description of each

## Can Be Added Later (Site Can Launch Without These, Added When Available)

- [ ] **Real membership prices** (site launches with clearly marked "Contact for pricing" placeholders until provided)
- [ ] **Testimonials/reviews** (name + quote, ideally with permission to use a photo) — can be added post-launch as they're collected
- [ ] **Certifications/awards** (any trainer certifications, gym awards or recognitions worth displaying)
- [ ] **Terms & Conditions content** (cancellation policy, freeze policy, etc.) — only needed if a Terms page is included
- [ ] **Additional gallery photos**, categorized (Gym / Equipment / Trainers / Training / Community) — can grow over time
- [ ] **FAQ content** — common questions members/prospects ask (trial policy, age restrictions, parking, etc.); a reasonable starter set can be drafted for review, but real answers should come from the owner

---

**Placeholder policy:** Anywhere real information isn't yet available, the site will display an explicit, clearly styled placeholder (e.g., "Pricing available on request" or a labeled "[Photo coming soon]" state) rather than an invented price, name, statistic, or claim — so nothing false is ever published, and swapping in real content later is a simple data-file edit.
